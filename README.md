# 🏧 Python ATM Management System

A simple command-line ATM Management System built using **Python**. This project allows users to perform basic banking operations through a menu-driven interface while demonstrating core Python programming concepts.

## ✨ Features

* Check Account Balance
* Deposit Money
* Withdraw Money
* User-Friendly Menu
* Input Validation
* Exception Handling

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming (OOP)

## 📁 Project Structure

```
python-atm-management-system/
│── atm.py
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python atm.py
```
